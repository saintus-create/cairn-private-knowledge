# Cairn typography

Cairn’s display stack names **Freight Text Pro** first for the wordmark and editorial headings. The font is not bundled in this project because it is a commercial typeface and no licensed webfont files were supplied. If a valid licensed webfont is later added through the project’s approved asset workflow, the existing CSS stack will use it automatically.

Until then, **Georgia** is the deliberate compatible fallback. The interface body remains a neutral Helvetica-based sans serif, preserving the compact, type-led reading rhythm without implying that Freight Text Pro has been licensed or distributed here.
